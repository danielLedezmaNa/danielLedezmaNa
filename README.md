## Qué hago · What I do

Construyo sitios web para negocios que viven de sus clientes locales: churrerías, cafeterías,
talleres, consultorios. Sitios rápidos, seguros y que aparecen en Google Maps cuando alguien
busca cerca.

> I build websites for businesses that live on local customers. Fast, secure, and findable —
> no templates, no page builders, no monthly plugin licenses.

| | |
|---|---|
| **Sitios de una página** | Menú, fotos, horarios y ubicación en un solo scroll |
| **SEO local** | Perfil de Empresa en Google, schema.org, NAP consistente |
| **Velocidad** | Core Web Vitals en verde, imágenes en WebP, sin frameworks pesados |
| **Seguridad** | HTTPS automático, encabezados de seguridad, hosting sin superficie de ataque |
| **Bilingüe** | Español e inglés en un mismo sitio, sin recargar la página |
